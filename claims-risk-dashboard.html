Methodology & notes
Built as a risk-advisory portfolio piece: descriptive analytics on a public motor-claims book, framed the way a broker's claims team reads a portfolio — exposure, severity mix, loss ratio and fraud incidence. All figures recompute live against active filters.
Loss-ratio caveat: in this synthetic dataset, settled amounts run far above annual premium, so the ratio is not a book-level solvency figure. It is used only as a relative index to compare underwriting pressure across segments. Fraud, severity and exposure figures are reported as-is.
